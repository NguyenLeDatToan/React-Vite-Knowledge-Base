# 🎨 Hướng dẫn Giao diện (UI Guide)

Tài liệu này mô tả các quy tắc thiết kế giao diện cho dự án.

---

## 📝 Quy tắc Markdown

### Emoji sử dụng

| Emoji | Ý nghĩa          |
| :---- | :--------------- |
| 📘    | Bài học          |
| 💡    | Mẹo/Tip          |
| ⚠️    | Cảnh báo         |
| ✅    | Hoàn thành/Đúng  |
| ❌    | Sai/Không nên    |
| 🚀    | Khởi động/Nhanh  |
| ⚙️    | Cấu hình         |
| 📦    | Package/Thư viện |
| 🌐    | Web/URL          |
| 🔌    | Port/Kết nối     |

### Code Blocks

- Sử dụng syntax highlighting: `bash`, `javascript`, `json`
- Thêm comment emoji trong code để giải thích

### Bảng (Tables)

- Căn trái cho text: `:---`
- Căn giữa cho số/icon: `:---:`
- Thêm emoji vào header
